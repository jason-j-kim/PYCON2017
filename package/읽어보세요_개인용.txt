정책 아이디어 평가 시스템 — 개인용
==================================

각자 자기 Claude 계정으로 씁니다.

이 폴더 안에 코드와 데이터가 다 들어 있습니다. 따로 받을 것이 없습니다.


■ 먼저 — 압축을 풀기 전에 한 가지

  내려받은 zip 을 오른쪽 클릭 → [속성] → 아래쪽 "보안:" 옆의
  [차단 해제] 에 체크 → [확인].

  이걸 하지 않으면 배치를 누를 때마다
  "게시자를 확인하지 못했습니다" 경고가 뜹니다.
  (경고가 떠도 [실행] 을 누르면 그대로 진행됩니다. 다만 매번 뜹니다.)

  그다음 압축을 풉니다.
  ※ OneDrive 폴더보다 C:\ 아래 같은 로컬 폴더를 권합니다.


■ 할 일은 이것뿐입니다

  1_설치.bat   더블클릭 (처음 한 번만)
  2_실행.bat   더블클릭 → 브라우저가 알아서 열립니다
  3_터널.bat   더블클릭 (외부에 공개할 때만, 2번을 켜 둔 채 새 창으로)

  끌 때는 2_실행.bat 창에서 Ctrl+C.
  파일을 복사하거나 편집할 일은 없습니다.

  창이 곧바로 닫히면 Python 이 없거나 PATH 에 없는 것입니다.
  python.org 에서 설치할 때 "Add python.exe to PATH" 를 꼭 체크하세요.
  확인: 명령창에서  python --version


■ 두 사람이 나뉩니다 — 설치하는 사람 / 실험하는 사람

  설치하는 사람은 PC 만 준비하면 됩니다. Claude 키는 만지지 않습니다.
  실험하는 사람이 2_실행.bat 을 켤 때 자기 키를 직접 넣습니다.

    1_설치.bat  ->  파이썬 패키지 (+ Node.js 가 있으면 Claude Code)
    2_실행.bat  ->  "API 키를 붙여넣으세요" 를 처음 한 번 물어봅니다

  0_제거.bat  401 이 사라지지 않을 때 지난번에 남은 키를 찾아 지웁니다
  4_키확인.bat 키가 왜 거부되는지 캐묻습니다
  둘 다 평소에는 쓸 일이 없습니다.


■ 미리 준비할 것

  Python 3.10 이상        python.org   (필수, "Add python.exe to PATH" 체크)

  그리고 실험하는 분이 Claude 를 부를 방법 하나:

    1) Anthropic API 키   <- 권장
       - 키만 있으면 됩니다. Node.js 도 Claude Code 도 필요 없습니다.
       - 발급: https://console.anthropic.com/settings/keys
         (sk-ant- 로 시작. 결제 수단 등록이 필요합니다.)
       - 쓴 만큼 본인 계정에 과금 - 아이디어 1건당 대략 300~600원.
       - 2_실행.bat 이 물어볼 때 붙여넣으면, 실제로 한 번 호출해
         확인한 뒤 씁니다. 잘못된 키는 그 자리에서 걸러집니다.

    2) Claude 구독 로그인
       - Pro 또는 Max 를 이미 쓰고 계신 경우에만.
       - Node.js 18 이상 설치와 브라우저 로그인이 필요합니다.
       - 추가 과금이 없습니다. 계정은 넘겨받을 수 없습니다.
       - 2_실행.bat 이 물어볼 때 그냥 Enter 를 누르면 이쪽입니다.

  기관 서버 - 폐쇄망이라면 1)이 맞습니다. 브라우저 로그인이 어렵고,
  키를 기관이 소유 - 회수할 수 있으며, 사용량이 콘솔에 남기 때문입니다.


■ 어느 것이 실제로 쓰이나 - 순서는 고정입니다

  API 키가 먼저입니다. 위에서부터 있는 것을 쓰고,
  API 키가 하나도 없을 때만 구독 로그인으로 내려갑니다.

    1순위  웹 화면에 넣은 API 키      그때그때. 서버에 저장하지 않습니다
    2순위  서버에 설정된 API 키       keys.local.bat 또는 환경변수
    3순위  Claude 구독 로그인         위 둘이 모두 없을 때만

  이 순서는 바뀌지 않습니다. 지금 3순위로 돌고 있더라도 키를 넣는
  순간 1순위로 올라갑니다 - 그때부터는 그 키의 계정에 과금됩니다.

  다만 이 순서는 기본값이지 강제가 아닙니다. 이 PC 에 Claude Code 가
  깔려 있고 로그인돼 있으면, 웹 화면 「Claude 연결」에 고르는 자리가
  나타납니다.

    ( ) API 키로        쓴 만큼 그 키의 계정에 과금
    ( ) 구독 로그인으로  추가 과금 없음

  키를 설정해 두었더라도 '구독 로그인으로'를 고르면 그 평가는 구독으로
  돕니다. 서버를 껐다 켤 필요가 없습니다. 고른 것이 우선순위보다 셉니다.

  3순위(구독)는 언제나 이 서버를 켜 둔 PC 에 로그인된 계정입니다.
  터널로 접속한 다른 사람의 Claude Pro 구독은 여기에 쓸 수 없습니다 -
  호출하는 주체가 그 사람의 브라우저가 아니라 이 서버이기 때문입니다.
  원격 참여자가 본인 계정으로 돌리려면 API 키뿐입니다.

  웹 화면 「Claude 연결」 칸이 지금 몇 순위로 돌고 있는지 그대로
  보여 줍니다. 화면에 넣은 키는 그 브라우저에만 남고 서버의
  sessions.db 나 로그에는 기록되지 않습니다.

  키를 넣으면 "이 폴더에 저장할까요?" 를 묻습니다.
    - 혼자 쓰는 PC       -> y  (다음부터 안 물어봅니다)
    - 여러 사람이 쓰는 PC -> N  (이번 실행에만 씁니다. 기본값)

  ※ 두 방법 모두 api.anthropic.com 으로 나가는 통신이 필요합니다.
    방화벽이 그 주소를 막으면 어느 쪽도 되지 않습니다.
    "닿지 못했습니다" 가 나오면 망 담당자에게 이 주소를 확인하세요.


■ 검증 통로는 네 개

  ① 재정      data\fiscal.json         키 불필요 · 바로 작동
  ② KDI 연구  data\kdi.sqlite          키 불필요 · 바로 작동
  ③ 국회 의안 open.assembly.go.kr      키 필요 (선택)
  ④ 해외사례  data\opsi_policies.db    키 불필요 · 바로 작동

  ③의 키는 웹 첫 화면에서 넣습니다. 파일을 고칠 일이 없습니다.
  [확인] 을 누르면 그 자리에서 되는지 알려줍니다.
  발급처는 열린국회정보(open.assembly.go.kr) — 공공데이터포털
  (data.go.kr) 키와는 다릅니다.

  넣은 키는 그 평가에만 쓰이고 서버에 저장되지 않습니다(문답 이력
  DB에도 남지 않습니다). "이 브라우저에 기억"을 켜면 본인 브라우저에만
  남습니다.

  키가 없어도 됩니다. 통로 상태는 결과 화면 "커버리지"에 셋으로
  구분되어 나옵니다.

    미실행     키·데이터가 없어 아예 돌리지 않음
    조회 실패  돌렸으나 오류로 결과를 못 받음 (망 장애 등)
    N건        실제로 조회한 결과

  앞의 둘은 판정 근거로 쓰이지 않습니다. "0건"과 다르게 처리되며,
  이런 통로가 있으면 판정기가 확신도를 '상'으로 올리지 않습니다.

■ 지금까지의 기록 보기 - /records

  평가 화면에서 「기록 보기」를 누르거나 주소창에
    http://localhost:8000/records

  지금까지 이 PC 에서 진행한 문답이 전부 목록으로 나옵니다.
  일시·아이디어·점수·턴 수, 그리고 채점과 선례 조사가 끝났는지.
  아이디어 내용으로 찾을 수도 있습니다.

  건마다 세 가지를 내려받습니다:

    보고서 (.docx)     채점이 끝난 것만. 5_보고서.bat 이 만드는 것과 같습니다
    문답 전문 (.txt)   채점 전이어도 받을 수 있습니다
    원자료 (.json)     이 화면의 「저장한 문답 불러오기」로 되불러 재평가할
                       수 있는 형태입니다

  [전부 내려받기 (.zip)] 는 모든 세션을 한 번에 담습니다.
  날짜_세션ID 폴더마다 문답.txt 와 (채점됐으면) 평가보고서.docx 가
  들어가고, 맨 위에 목록.txt 가 붙습니다.

  ※ 이 화면은 서버를 켜 둔 그 PC 에서만 열립니다. 터널 주소로는
    열리지 않습니다 - sessions.db 에는 여러 사람의 문답이 함께
    쌓이므로, 접속한 사람이 남의 대화를 받아 갈 수 있으면 안 됩니다.
    초대 코드로 막는 것으로는 부족합니다(참여자 전원이 아는 값입니다).


■ 보고서로 받기 - 5_보고서.bat

  평가가 끝나면 화면에서 스크롤하며 읽는 것 말고 Word 문서로 받을 수
  있습니다. 5_보고서.bat 을 더블클릭하면 가장 최근에 끝난 평가로
  폴더에 평가보고서_<세션ID>_<날짜>.docx 를 만듭니다.

  담기는 것:

    1. 종합 판정      가중 총점 · 평가 범위 · 근거 신뢰도 · 실질 독창성
                      · 네 칸 위치(추진/재포지셔닝/보완 후 재문답/보류)
    2. 다섯 문장 요약  누가 · 어떤 문제를 · 어떻게 · 무엇이 다른가 · 근거
    3. 축 A 방어력    세 기준별 최종점수와 체크리스트 10항목 판정 전부
                      (체크리스트와 종합판단의 괴리 처리까지 적습니다)
    4. 축 B 실질 독창성 판정·확신도·근거 등급(A/B)·검증 통로 커버리지
    5. 강점과 보완
    부록. 대화 전문   12문답 전체. 점수에 의문이 들면 여기를 봅니다.

  커버리지 표는 통로마다 미실행 / 조회 실패 / N건 을 구분해 적습니다.
  앞의 둘은 "선례가 없다"가 아니라 "확인하지 못했다"는 뜻이며, 보고서
  안에도 그 뜻이 그대로 적힙니다.

  다른 세션으로 만들려면:
    python webapp\make_report.py --list      먼저 목록을 봅니다
    python webapp\make_report.py <세션ID>

  PDF 가 필요하면 Word 에서 [파일] -> [다른 이름으로 저장] -> PDF.

■ 401 이 계속될 때 - 0_제거.bat

  대개 코드가 아니라 지난번에 남은 값이 원인입니다. 키는 네 군데에
  남고, 하나라도 살아 있으면 새 zip 을 풀어도 그대로 따라옵니다.

    1) 브라우저에 저장한 키    1순위 - 서버 설정을 이깁니다
    2) keys.local.bat          2순위 - 폴더 안
    3) 윈도우 사용자 환경변수   2순위 - 폴더를 지워도 남습니다
    4) __pycache__             옛 코드가 실행될 수 있습니다

  셋째가 특히 고약합니다. 폴더를 통째로 지우고 새로 풀어도 살아남아
  "새로 받았는데 왜 똑같지" 가 됩니다.

  0_제거.bat 을 더블클릭하면 2)3)4)를 찾아 보여주고 지웁니다.
  연구 자료(webapp\sessions.db)는 건드리지 않습니다.

  1) 브라우저 키만 스크립트가 손댈 수 없습니다. 둘 중 아무거나:

    - 2_실행.bat 을 켠 뒤 주소창에
      http://localhost:8000/policy?reset=1
    - 평가 화면 「Claude 연결」의 [비우고 서버 설정으로] 단추

  그런 다음 검은 창을 모두 닫고 2_실행.bat 을 다시 켜세요.

■ "키는 분명히 맞는데 401" - 4_키확인.bat

  대개 키가 틀린 게 아니라 붙여넣는 동안 망가진 것입니다.
  눈으로는 구별되지 않습니다.

    · 문서나 메일에서 복사하면 가운데에 공백이나 줄바꿈이 섞입니다
    · 워드·한글에서 복사하면 보이지 않는 문자가 딸려옵니다
    · 콘솔의 키 목록 화면은 만들 때 한 번만 전체를 보여줍니다.
      나중에 다시 들어가 복사하면 잘린 값을 가져오게 됩니다

  Anthropic 은 이 셋을 구분해 주지 않고 모두 "API key is invalid" 로만
  답합니다. 그래서 화면만 보고는 원인을 알 수 없습니다.

  check_claude.py 는 부르기 전에 글자를 하나하나 먼저 봅니다.
  길이·머리말·섞여든 글자를 몇 번째 자리인지까지 찍어 줍니다.
  그다음 실제로 한 번 불러 Anthropic 의 답을 그대로 보여줍니다.

    4_키확인.bat 을 더블클릭
      (붙여넣으라고 물어봅니다. 웹 화면에 넣은 것과 똑같은 방법으로
       복사해 오셔야 합니다. 여기서만 다시 정성껏 치면 원인을 놓칩니다.)

    결과는 폴더의 키확인_결과.txt 에도 남습니다. 창이 닫혀도 읽을 수
    있고, 남에게 보여줄 때 그 파일을 보내시면 됩니다. 키 전체는
    그 파일에 들어가지 않습니다.

  웹 화면도 같은 검사를 합니다. 「Claude 연결」 칸에 넣는 순간
  "이대로는 거부됩니다 - 21번째 자리에 공백" 처럼 빨갛게 알려 줍니다.

  키가 정말 폐기됐거나 다른 조직의 것이면 새로 만드는 수밖에 없습니다.
  https://console.anthropic.com/settings/keys 에서 새 키를 만들고
  그 자리에서 바로 복사하세요.
