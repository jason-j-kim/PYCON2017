정책 아이디어 평가 시스템 — 실험용
==================================

기관이 Claude 키 하나로 운영하고, 참여자는 초대 코드만 넣습니다.
참여자는 키를 준비할 필요가 없습니다.

이 폴더 안에 코드와 데이터가 다 들어 있습니다. 따로 받을 것이 없습니다.


■ 이 문서는 운영자용입니다

  운영자   이 문서를 읽고 서버를 켭니다. 키와 초대 코드를 정합니다.
  참여자   주소와 초대 코드만 받습니다. 아무것도 설치하지 않습니다.


■ 먼저 — 압축을 풀기 전에 한 가지

  내려받은 zip 을 오른쪽 클릭 → [속성] → 아래쪽 "보안:" 옆의
  [차단 해제] 에 체크 → [확인]. 그다음 압축을 풉니다.

  ※ OneDrive 폴더보다 C:\ 아래 같은 로컬 폴더를 권합니다.


■ 운영자가 할 일은 셋뿐입니다

  1_설치.bat   더블클릭 (처음 한 번만) — 여기서 키와 초대 코드를 정합니다
  2_실행.bat   더블클릭 → 브라우저가 알아서 열립니다
  3_터널.bat   더블클릭 (참여자가 원격이면. 2번을 켜 둔 채 새 창으로)

  0_제거.bat 도 들어 있습니다. 401 이 사라지지 않을 때 지난번에 남은
  키(keys.local.bat · 윈도우 환경변수 · __pycache__)를 찾아 지웁니다.
  연구 자료 sessions.db 는 건드리지 않습니다. 평소에는 쓸 일이 없습니다.

  끌 때는 2_실행.bat 창에서 Ctrl+C.

  창이 곧바로 닫히면 Python 이 없거나 PATH 에 없는 것입니다.
  python.org 에서 설치할 때 "Add python.exe to PATH" 를 꼭 체크하세요.


■ 미리 준비할 것

  Python 3.10 이상          python.org  (필수)

  Anthropic API 키          https://console.anthropic.com/settings/keys
    - sk-ant- 로 시작하는 긴 문자열. 결제 수단 등록이 필요합니다.
    - 참여자 전원의 호출이 이 키 하나로 과금됩니다.
    - 아이디어 1건당 대략 300~600원. 100건이면 3~6만원 수준입니다.
    - 콘솔에서 이 키에 사용 한도를 걸어 두시길 권합니다.

  Node.js 는 필요 없습니다. Claude Code 도 설치하지 않습니다.


■ 1_설치.bat 이 묻는 것

  [1/2] 파이썬 패키지 설치        (자동)
  [운영 설정]
     1) Anthropic API 키 (필수)
        붙여넣으면 실제로 한 번 호출해 확인한 뒤 저장합니다.
        키가 잘못됐으면 그 자리에서 알려줍니다.
     2) 초대 코드 (참여자에게 알려 줄 값)
        기본값 kdi2026. 바꾸시길 권합니다.
     3) 국회 의안 인증키 (선택)
        https://open.assembly.go.kr 에서 발급.
        없으면 ③ 통로만 꺼지고 나머지 셋은 그대로 작동합니다.

  세 값은 keys.local.bat 에 저장됩니다. 이 파일은 기관의 것입니다 —
  참여자에게 주지 마세요.


■ 참여자에게 알려 줄 것 — 두 가지뿐

  · 주소       3_터널.bat 이 찍어 주는 https://....trycloudflare.com/policy
               (2_실행.bat 만 쓰면 http://localhost:8000/policy)
  · 초대 코드   1_설치.bat 에서 정한 값

  참여자 화면에는 키 입력칸이 나오지 않습니다. 초대 코드만 넣고
  정책을 서술하면 12문답이 시작됩니다.


■ 검증 통로는 네 개

  ① 재정      data\fiscal.json         키 불필요 · 바로 작동
  ② KDI 연구  data\kdi.sqlite          키 불필요 · 바로 작동
  ③ 국회 의안 open.assembly.go.kr      운영자가 설치 때 넣습니다 (선택)
  ④ 해외사례  data\opsi_policies.db    키 불필요 · 바로 작동

  통로 상태는 결과 화면 "커버리지"에 셋으로 구분되어 나옵니다.

    미실행     키·데이터가 없어 아예 돌리지 않음
    조회 실패  돌렸으나 오류로 결과를 못 받음 (망 장애 등)
    N건        실제로 조회한 결과

  앞의 둘은 판정 근거로 쓰이지 않습니다. "0건"과 다르게 처리되며,
  이런 통로가 있으면 판정기가 확신도를 '상'으로 올리지 않습니다.

■ 실험 자료는 어디에 쌓이나

  webapp\sessions.db 에 문답·채점·선례 판정이 모두 쌓입니다.
  사람이 읽을 형태로 보려면:   python webapp\show_session.py

  이 파일이 연구 자료입니다. 참여자에게 배포하는 zip 에는 넣지 마세요
  (개인정보가 담길 수 있습니다).

  하루 세션 수는 기본 30건으로 제한됩니다. 늘리려면 keys.local.bat 에
  set SOCRATIC_MAX_SESSIONS_PER_DAY=100 처럼 넣으세요.


■ 지금까지의 기록 보기 - /records

  평가 화면에서 「기록 보기」를 누르거나 주소창에
    http://localhost:8000/records

  지금까지 이 PC 에서 진행한 문답이 전부 목록으로 나옵니다.
  일시·아이디어·점수·턴 수, 그리고 채점과 선례 조사가 끝났는지.
  아이디어 내용으로 찾을 수도 있습니다.

  건마다 세 가지를 내려받습니다:

    보고서 (.docx)     채점이 끝난 것만. 5_보고서.bat 이 만드는 것과 같습니다
    문답 전문 (.txt)   채점 전이어도 받을 수 있습니다
    원자료 (.json)     이 화면의 「저장한 문답 불러오기」로 되불러 재평가할
                       수 있는 형태입니다

  [전부 내려받기 (.zip)] 는 모든 세션을 한 번에 담습니다.
  날짜_세션ID 폴더마다 문답.txt 와 (채점됐으면) 평가보고서.docx 가
  들어가고, 맨 위에 목록.txt 가 붙습니다.

  ※ 이 화면은 서버를 켜 둔 그 PC 에서만 열립니다. 터널 주소로는
    열리지 않습니다 - sessions.db 에는 여러 사람의 문답이 함께
    쌓이므로, 접속한 사람이 남의 대화를 받아 갈 수 있으면 안 됩니다.
    초대 코드로 막는 것으로는 부족합니다(참여자 전원이 아는 값입니다).


■ 보고서로 받기 - 5_보고서.bat

  평가가 끝나면 화면에서 스크롤하며 읽는 것 말고 Word 문서로 받을 수
  있습니다. 5_보고서.bat 을 더블클릭하면 가장 최근에 끝난 평가로
  폴더에 평가보고서_<세션ID>_<날짜>.docx 를 만듭니다.

  담기는 것:

    1. 종합 판정      가중 총점 · 평가 범위 · 근거 신뢰도 · 실질 독창성
                      · 네 칸 위치(추진/재포지셔닝/보완 후 재문답/보류)
    2. 다섯 문장 요약  누가 · 어떤 문제를 · 어떻게 · 무엇이 다른가 · 근거
    3. 축 A 방어력    세 기준별 최종점수와 체크리스트 10항목 판정 전부
                      (체크리스트와 종합판단의 괴리 처리까지 적습니다)
    4. 축 B 실질 독창성 판정·확신도·근거 등급(A/B)·검증 통로 커버리지
    5. 강점과 보완
    부록. 대화 전문   12문답 전체. 점수에 의문이 들면 여기를 봅니다.

  커버리지 표는 통로마다 미실행 / 조회 실패 / N건 을 구분해 적습니다.
  앞의 둘은 "선례가 없다"가 아니라 "확인하지 못했다"는 뜻이며, 보고서
  안에도 그 뜻이 그대로 적힙니다.

  다른 세션으로 만들려면:
    python webapp\make_report.py --list      먼저 목록을 봅니다
    python webapp\make_report.py <세션ID>

  PDF 가 필요하면 Word 에서 [파일] -> [다른 이름으로 저장] -> PDF.



■ 비용 관리

  · 콘솔(console.anthropic.com)에서 이 키의 사용량과 청구액을 봅니다.
  · 키마다 사용 한도(spend limit)를 걸 수 있습니다. 실험 전에 거세요.
  · 실험이 끝나면 콘솔에서 그 키를 폐기하시면 됩니다.
  · 초대 코드를 아는 사람만 평가를 시작할 수 있습니다. 코드가 새면
    1_설치.bat 을 다시 실행해 바꾸세요.

                                1_설치.bat 을 다시 실행해 키를 넣으세요

  의안 통로가 의심스러우면      python webapp\check_bill.py

                                섞여든 공백·보이지 않는 문자·잘린 값을
                                몇 번째 자리인지까지 찍어 줍니다.
                                "키는 맞는데 401" 의 대부분이 이것입니다.

                                키를 지우고, 1_설치.bat 으로 다시 넣으세요.
                                그래도 401 이면 키 자체의 문제입니다 —
                                콘솔에서 키·결제 수단·사용 한도 확인
  터널 주소는 뜨는데 안 열림      2_실행.bat 이 꺼져 있음
                                → localhost:8000 부터 확인

  ※ api.anthropic.com 으로 나가는 통신이 필요합니다. 방화벽이 막으면
    작동하지 않습니다. 망 담당자에게 이 주소를 확인하세요.
