정책 아이디어 평가 시스템 — 터널판
====================================

이 폴더 안에 코드와 데이터가 다 들어 있습니다. 따로 받을 것이 없습니다.


■ 먼저 — 압축을 풀기 전에 한 가지

  내려받은 zip 을 오른쪽 클릭 → [속성] → 아래쪽 "보안:" 옆의
  [차단 해제] 에 체크 → [확인].

  이걸 하지 않으면 배치를 누를 때마다
  "게시자를 확인하지 못했습니다" 경고가 뜹니다.
  (경고가 떠도 [실행] 을 누르면 그대로 진행됩니다. 다만 매번 뜹니다.)

  그다음 압축을 풉니다.
  ※ OneDrive 폴더보다 C:\ 아래 같은 로컬 폴더를 권합니다.


■ 할 일은 이것뿐입니다

  1_설치.bat   더블클릭 (처음 한 번만)
  2_실행.bat   더블클릭 → 브라우저가 알아서 열립니다
  3_터널.bat   더블클릭 (외부에 공개할 때만, 2번을 켜 둔 채 새 창으로)

  끌 때는 2_실행.bat 창에서 Ctrl+C.
  파일을 복사하거나 편집할 일은 없습니다.

  창이 곧바로 닫히면 Python 이 없거나 PATH 에 없는 것입니다.
  python.org 에서 설치할 때 "Add python.exe to PATH" 를 꼭 체크하세요.
  확인: 명령창에서  python --version


■ 미리 준비할 것

  Python 3.10 이상        python.org  (필수)

  그리고 Claude 를 부르는 방법을 둘 중 하나 고릅니다.

  ┌─ 방법 A. 구독 로그인 (개인 연구자에게 권장) ───────────────┐
  │  필요한 것: Node.js 18 이상 + Claude 구독(Pro/Max)         │
  │  1_설치.bat 이 Claude Code 를 깔고 /login 까지 안내합니다. │
  │  구독료 안에서 쓰므로 추가 과금이 없습니다.                │
  │  계정은 넘겨받을 수 없습니다 — 각자 자기 계정으로 합니다.  │
  └────────────────────────────────────────────────────────────┘

  ┌─ 방법 B. API 키 (기관 서버·폐쇄 환경에 권장) ──────────────┐
  │  필요한 것: Anthropic Console 의 API 키                    │
  │  Node.js 도 Claude Code 도 필요 없습니다.                  │
  │                                                            │
  │  이 폴더에 keys.local.bat 이라는 파일을 만들고             │
  │  메모장으로 아래 두 줄을 넣어 저장하면 끝입니다.           │
  │                                                            │
  │      @echo off                                             │
  │      set ANTHROPIC_API_KEY=sk-ant-여기에키                 │
  │                                                            │
  │  쓴 만큼 과금됩니다(아이디어 1건당 대략 300~600원).        │
  └────────────────────────────────────────────────────────────┘

  어느 쪽인지는 2_실행.bat 이 켤 때 화면에 찍어 주고,
  웹 첫 화면의 「Claude 연결」 칸에도 나옵니다.

      Claude    : 구독 로그인 방식 (claude CLI)
      Claude    : API 키 방식 (키 sk-ant-…abcd · 모델 ...)

  ※ 웹 첫 화면에서 방문자가 자기 API 키를 넣을 수도 있습니다(선택).
    그 경우 우선순위는 이렇습니다.

        1. 화면에 넣은 키        <- 가장 우선
        2. 서버 설정(keys.local.bat)
        3. 구독 로그인            <- 아무 키도 없을 때

    화면에 넣은 키는 그 평가에만 쓰이고 서버에 저장되지 않습니다.
    방문자의 '구독'은 확인할 방법이 없습니다 - Claude 를 부르는 주체가
    방문자가 아니라 이 서버이기 때문입니다. 그래서 구독 증명 칸은
    두지 않고, 서버가 어떻게 연결돼 있는지만 정직하게 보여줍니다.

  방법 B 에서 A 로 돌아가려면 keys.local.bat 을 지우면 됩니다.
  파일 하나를 넣고 빼는 것이 전부입니다. 환경변수를 건드리지 않습니다.

  keys.local.bat 은 각자 자기 것입니다. 남에게 주지 마세요.

  ※ 두 방법 모두 api.anthropic.com 으로 나가는 통신이 필요합니다.
    방화벽이 그 주소를 막으면 어느 쪽도 되지 않습니다.


■ 1_설치.bat 이 하는 일

  [1/3] 파이썬 패키지 설치
  [2/3] Claude Code 설치      ← 방법 B(API 키)면 건너뜁니다
  [3/3] Claude 로그인          ← 방법 B면 건너뜁니다

  마지막에 어느 방법으로 도는지 알려줍니다.
  국회 의안 키는 여기서 넣지 않습니다 — 웹 첫 화면에서 넣습니다.


■ 검증 통로는 네 개

  ① 재정      data\fiscal.json         키 불필요 · 바로 작동
  ② KDI 연구  data\kdi.sqlite          키 불필요 · 바로 작동
  ③ 국회 의안 open.assembly.go.kr      키 필요 (선택)
  ④ 해외사례  data\opsi_policies.db    키 불필요 · 바로 작동

  ③의 키는 웹 첫 화면에서 넣습니다. 파일을 고칠 일이 없습니다.
  [확인] 을 누르면 그 자리에서 되는지 알려줍니다.
  발급처는 열린국회정보(open.assembly.go.kr) — 공공데이터포털
  (data.go.kr) 키와는 다릅니다.

  넣은 키는 그 평가에만 쓰이고 서버에 저장되지 않습니다(문답 이력
  DB에도 남지 않습니다). "이 브라우저에 기억"을 켜면 본인 브라우저에만
  남습니다.

  키가 없어도 됩니다. 통로 상태는 결과 화면 "커버리지"에 셋으로
  구분되어 나옵니다.

    미실행     키·데이터가 없어 아예 돌리지 않음
    조회 실패  돌렸으나 오류로 결과를 못 받음 (망 장애 등)
    N건        실제로 조회한 결과

  앞의 둘은 판정 근거로 쓰이지 않습니다. "0건"과 다르게 처리되며,
  이런 통로가 있으면 판정기가 확신도를 '상'으로 올리지 않습니다.


■ 폴더 안에 무엇이 있나

  data\        평가에 쓰는 데이터 3개
                 fiscal.json         세출예산 14,122개 사업
                 kdi.sqlite          KDI 발간물 7,362건
                 opsi_policies.db    OECD OPSI 해외사례 1,015건 · 98개국
  webapp\      웹 서버와 화면
  socratic\    문답·채점 엔진과 프롬프트
  kdinov\      KDI 코퍼스 정밀 판정기

  배치 파일은 "python OO.py" 한 줄만 합니다. 한국어 안내와 로직은
  전부 .py 안에 있습니다 — 배치에 한국어를 넣으면 윈도우 인코딩에
  따라 깨지기 때문입니다.


■ 접속 코드

  기본값은 kdi2026 입니다. 바꾸려면 start.py 위쪽의
  DEFAULT_CODE = "kdi2026"  을 고치세요.
  접속한 사람이 이 코드를 입력해야 평가를 시작합니다.


■ 문답 이력

  webapp\sessions.db 에 쌓입니다. 사람이 읽을 형태로 보려면
  명령창에서:   python webapp\show_session.py
