정책 아이디어 평가 시스템 — 터널판
====================================

이 폴더 안에 코드와 데이터가 다 들어 있습니다. 따로 받을 것이 없습니다.


■ 먼저 — 압축을 풀기 전에 한 가지

  내려받은 zip 을 오른쪽 클릭 → [속성] → 아래쪽 "보안:" 옆의
  [차단 해제] 에 체크 → [확인].

  이걸 하지 않으면 배치를 누를 때마다
  "게시자를 확인하지 못했습니다" 경고가 뜹니다.
  (경고가 떠도 [실행] 을 누르면 그대로 진행됩니다. 다만 매번 뜹니다.)

  그다음 압축을 풉니다.
  ※ OneDrive 폴더보다 C:\ 아래 같은 로컬 폴더를 권합니다.


■ 할 일은 이것뿐입니다

  1_설치.bat   더블클릭 (처음 한 번만)
  2_실행.bat   더블클릭 → 브라우저가 알아서 열립니다
  3_터널.bat   더블클릭 (외부에 공개할 때만, 2번을 켜 둔 채 새 창으로)

  끌 때는 2_실행.bat 창에서 Ctrl+C.
  파일을 복사하거나 편집할 일은 없습니다.

  창이 곧바로 닫히면 Python 이 없거나 PATH 에 없는 것입니다.
  python.org 에서 설치할 때 "Add python.exe to PATH" 를 꼭 체크하세요.
  확인: 명령창에서  python --version


■ 미리 준비할 것

  Python 3.10 이상        python.org
  Node.js 18 이상         nodejs.org
  Claude 구독 계정        Pro 또는 Max

  Claude 계정은 넘겨받을 수 없습니다. 1_설치.bat 이 /login 하는
  자리까지 데려다 줍니다.


■ 1_설치.bat 이 하는 일

  [1/4] 파이썬 패키지 설치
  [2/4] Claude Code 설치
  [3/4] Claude 로그인 (/login 입력 → /exit)
  [4/4] 국회 의안 키 입력 — 선택. Enter 로 건너뛸 수 있습니다.
        키를 넣으면 파일 생성과 동작 확인까지 자동으로 합니다.

  키를 바꾸려면 keys.local.bat 을 지우고 1_설치.bat 을 다시 실행하세요.
  keys.local.bat 은 각자 자기 것입니다. 남에게 주지 마세요.


■ 검증 통로는 네 개

  ① 재정      data\fiscal.json         키 불필요 · 바로 작동
  ② KDI 연구  data\kdi.sqlite          키 불필요 · 바로 작동
  ③ 국회 의안 open.assembly.go.kr      키 필요 (선택)
  ④ 해외사례  data\opsi_policies.db    키 불필요 · 바로 작동

  ③의 키는 열린국회정보(open.assembly.go.kr)에서 발급합니다.
  공공데이터포털(data.go.kr) 키와는 다릅니다.

  키가 없어도 됩니다. 통로 상태는 결과 화면 "커버리지"에 셋으로
  구분되어 나옵니다.

    미실행     키·데이터가 없어 아예 돌리지 않음
    조회 실패  돌렸으나 오류로 결과를 못 받음 (망 장애 등)
    N건        실제로 조회한 결과

  앞의 둘은 판정 근거로 쓰이지 않습니다. "0건"과 다르게 처리되며,
  이런 통로가 있으면 판정기가 확신도를 '상'으로 올리지 않습니다.


■ 폴더 안에 무엇이 있나

  data\        평가에 쓰는 데이터 3개
                 fiscal.json         세출예산 14,122개 사업
                 kdi.sqlite          KDI 발간물 7,362건
                 opsi_policies.db    OECD OPSI 해외사례 1,015건 · 98개국
  webapp\      웹 서버와 화면
  socratic\    문답·채점 엔진과 프롬프트
  kdinov\      KDI 코퍼스 정밀 판정기
  setup.py     1_설치.bat 이 실제로 하는 일
  start.py     2_실행.bat 이 실제로 하는 일
  tunnel.py    3_터널.bat 이 실제로 하는 일

  배치 파일은 "python OO.py" 한 줄만 합니다. 한국어 안내와 로직은
  전부 .py 안에 있습니다 — 배치에 한국어를 넣으면 윈도우 인코딩에
  따라 깨지기 때문입니다.


■ 접속 코드

  2_실행.bat 안의  SOCRATIC_ACCESS_CODE=kdi2026  을 원하는 값으로
  바꾸세요. 접속한 사람이 이 코드를 입력해야 평가를 시작합니다.


■ 문답 이력

  webapp\sessions.db 에 쌓입니다. 사람이 읽을 형태로 보려면
  명령창에서:   python webapp\show_session.py
