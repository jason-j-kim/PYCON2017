## 1. 어느 판을 넘기나 — 터널판이 원전이다

세 배포가 있지만 **연구용 원전은 터널판**이다. 이유는 하나다.

| 판 | kdinov 정밀 판정 | Word·PDF | 세션 저장 | 연구용 적합성 |
|---|---|---|---|---|
| **터널** | ✅ 중첩도·역할 판정 | ✅ | 서버 SQLite에 **축적** | **원전** |
| Vercel | ✅ | ✅ | 브라우저에만 | 공개 시연용 |
| Workers | ❌ 키워드 조회만 | ❌ | 브라우저에만 | 미검증 |

터널판만이 **문답·채점 이력을 서버에 축적**한다. 연구 자료를 모으려면 이 판이어야
한다. Vercel·Workers는 서버가 무상태라 세션이 브라우저에만 남는다.

**Vercel판도 함께 넘어간다** — 저장소에 코드와 코퍼스가 다 들어 있어, 연구자가
자기 Vercel 계정에 배포하면 바로 공개 시연이 가능하다.

## 2. 데이터 — 무엇이 저장소에 있고 무엇이 아닌가

### 저장소에 들어 있다 (clone하면 따라옴)

```
web/api/fiscal.json          2.7MB   세출예산 14,122개 사업
web/api/kdi.sqlite           26MB    KDI 발간물 7,362건 (본문 제거 경량본)
web/api/opsi_policies.db     15MB    OPSI 해외사례 1,015건 · 98개국
```

### 별도 전달 (git 제외)

```
kdi/kdi.sqlite               53MB    KDI 원본 — 본문 포함
```

이 파일이 **kdinov 2차원 판정의 재료**다. 없으면 KDI 통로가 키워드 조회로 자동
강등된다(작동은 한다).

`overseas/opsi_policies.db`는 `web/api/`의 것과 동일하므로 복사하면 된다.

### 파일이 없으면 어떻게 되나

**멈추지 않는다.** 각 통로가 데이터 유무를 스스로 확인해 켜지고 꺼진다. 꺼진 통로는
결과 화면 커버리지에 "미실행"으로 표시되고, 판정기가 그 사실을 반영해 확신도를
낮춘다. 데이터가 하나도 없어도 문답과 채점(축 A)은 정상 동작한다.

## 3. 설치 — 처음부터 끝까지

### 3.1 저장소와 데이터

```bat
git clone <저장소 주소> PYCON2017
cd PYCON2017

REM 별도 전달받은 원본을 제자리에
copy <받은경로>\kdi.sqlite kdi\kdi.sqlite
copy web\api\opsi_policies.db overseas\opsi_policies.db
```

### 3.2 파이썬 패키지

```bat
pip install -r webapp\requirements.txt
pip install kiwipiepy
```

`kiwipiepy`는 선택이다. 없으면 한국어 문장 분할이 정규식으로 퇴화하지만 판정은
그대로 돌아간다.

### 3.3 Claude Code CLI — 본인 계정으로

```bat
npm install -g @anthropic-ai/claude-code
claude
```

`claude` 실행 후 **`/login`** 으로 본인 계정에 로그인한다. 한 번 로그인하면 유지된다.

> `ANTHROPIC_API_KEY` 환경변수가 설정돼 있으면 CLI 로그인보다 우선해 인증 오류가
> 날 수 있다. 문제가 생기면 `set ANTHROPIC_API_KEY=` 로 지운다.

### 3.4 국회 의안 키 (선택)

공공데이터포털에서 국회 의안정보 API 키를 발급받아 지정한다.

```bat
set ASSEMBLY_KEY=발급받은키
```

없으면 ③ 국회 의안 통로만 꺼지고 나머지 세 통로는 정상이다.

### 3.5 점검

```bat
python check_setup.py
```

파이썬 버전·패키지·CLI·네 통로 코퍼스·포트·초대 코드를 한 번에 확인하고,
**빠진 것과 조치 방법을 알려준다.** Claude 로그인까지 확인하려면 `--deep`을 붙인다.

## 4. 실행

```bat
set SOCRATIC_ACCESS_CODE=원하는코드
python webapp\app.py
```

`Uvicorn running on http://127.0.0.1:8000` 이 뜨면 브라우저에서
**`http://localhost:8000/policy`** 를 연다.

외부 공개가 필요하면 **다른 창**에서:

```bat
cloudflared tunnel --url http://localhost:8000
```

출력된 주소 뒤에 `/policy`를 붙여 공유한다. **실행할 때마다 주소가 바뀐다.**
고정 주소가 필요하면 Cloudflare에 도메인을 두고 Named Tunnel을 쓴다
(`worker/README.md` 마지막 절).

### 자주 나는 오류

| 증상 | 원인 · 조치 |
|---|---|
| `[Errno 10048]` | 포트 8000을 이전 서버가 잡고 있음 → `taskkill /F /IM python.exe` |
| `No such file or directory` | 폴더가 틀림 → `cd /d C:\...\PYCON2017` |
| 터널은 뜨는데 페이지가 안 열림 | 서버가 안 켜짐 → **localhost부터** 확인 |
| `claude CLI를 찾을 수 없습니다` | CLI 미설치 또는 새 터미널 필요 |
| 인증 실패(401) | `claude` 실행 → `/login`, 또는 `ANTHROPIC_API_KEY` 제거 |

**서버를 끌 때는 반드시 `Ctrl+C`.** 창을 X로 닫으면 포트가 남아 다음 실행에서
10048이 난다.

## 5. 연구 자료는 어디에 쌓이나

```
webapp/sessions.db        문답·채점·선례 판정 이력 (서버 SQLite)
simulation/results/       시뮬레이션 원자료
```

`sessions.db`는 git 제외 대상이다. 연구 자료를 넘기고 받을 때는 이 파일을 별도로
주고받는다.

세션 내용을 사람이 읽을 형태로 보려면:

```bat
python webapp\show_session.py
```

## 6. 인계받은 뒤 가장 먼저 할 일

1. **`python check_setup.py`** — 환경이 갖춰졌는지 확인
2. **정책 하나를 끝까지 평가해 본다** — 12문답을 실제로 답하고 결과까지 확인
3. **`docs/HANDOFF_인수인계.md` 6장**을 읽는다 — 이미 내려진 결정 9건이 정리돼 있어,
   같은 논의를 반복하지 않아도 된다
4. **`docs/대화기반_아이디어평가_방법론.md` 6부**를 읽는다 — 미해결 쟁점 30항목

### 손대지 말아야 할 것

- **체크리스트 30항목의 문안** — 바꾸면 기존 세션과 비교가 불가능해진다
  (개선안은 설계돼 있으나 의도적으로 보류 상태다)
- **가중치 35/35/30** — 연구 세션 간 비교 가능성을 위해 고정
- 이미 배제된 선택지(봇 우회 수집, 외국 유료 정책DB) — 근거는 인수인계 문서 6장
