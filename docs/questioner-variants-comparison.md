# 질문자 지침 개정 3안 비교

기존 안(`socratic/prompts/questioner_system.md`)의 관찰된 문제 4가지 —
① 기계적·반복적 인정, ② 회피 방치, ③ 질문 도구 사용 편중, ④ 힌트 규칙
미발동 — 를 모두 고치되, 소크라테스 문답법의 서로 다른 측면을 중심에 둔
3가지 개정안. 파일은 `socratic/prompts/variants/`에 있다.

## 한눈 비교

| | 제1안 논박형 (엘렝코스) | 제2안 산파술형 (마이에우틱스) | 제3안 변증법 절차형 |
|---|---|---|---|
| 철학적 뿌리 | 초기 대화편의 논박 — 모순을 드러내 스스로 무너지게 함 | 테아이테토스의 산파술 — 스스로 낳은 결론만이 그의 것 | 문답을 표준 검증 절차로 설계 — 일관성이 공정성 |
| 핵심 기법 | 발언 간 모순 대질, 숨은 전제 추적 | 큰 질문을 쪼개서 묻기, 제안자의 언어 인용, 아포리아를 성과로 확인 | 라운드마다 정의→검증→함의의 3단 고정 절차 |
| 회피 대응 | 회피 명시 → 좁혀 재질문 → "미답변으로 남습니다" 선언 (힌트 없음) | 쪼갠 질문으로 우회 접근, 막히면 생각의 발판 제공 | 짚고 재질문 → 선택지형 질문(A/B/모름)으로 강제 구조화 → 미답변 선언 |
| 인정 | 반례를 소화했을 때만 (가장 절제) | 새 구체성·자기 인식이 나왔을 때만 | 세션당 최대 4회의 인정 예산 |
| 제안자 체감 | 긴장감, 시험받는 느낌 | 도움받는 느낌, 심리적 안전 | 공정하고 예측 가능한 느낌 |
| 채점과의 궁합 | 일관성·정면응답 항목 판별에 유리 | 자기인식 항목 유도에 유리 | 도구 커버리지 보장 → 모든 항목에 고른 증거 생성 |
| 주요 위험 | 심문처럼 느껴져 위축·방어적 답변 유발 가능 | 발판 제공이 답 대주기로 변질될 수 있음, 압박 부족으로 판별력 저하 가능 | 절차가 기계적으로 느껴질 수 있음, 대화의 자연스러운 흐름 희생 |
| 적합한 용도 | 숙련된 제안자, 투자 심사처럼 검증이 목적일 때 | 학생·초심자, 교육이 목적일 때 | 다수를 공정 비교해야 할 때(공모전·수업 평가) |

## 검증 방법 (제안)

같은 제안자 페르소나(진부 1 + 창의 1)로 세 안을 각각 시뮬레이션하여 비교:

1. **판별력** — 진부/창의 점수 격차가 어느 안에서 가장 큰가
2. **회피 검출** — 진부 페르소나의 회피에 몇 번 개입했는가 (대화에서 계수)
3. **자기 인식 유도** — 자기인식 관련 체크리스트 항목(O9·P9·A9) 충족률
4. **도구 커버리지** — 6가지 질문 도구가 실제로 몇 종 사용되었는가
5. **체감 어조** — 대화를 읽고 심문/조력/절차 느낌을 정성 평가

총 6세션(3안 × 진부·창의), 소요 약 70분. 결과에 따라 하나를 채택하거나,
용도별로 골라 쓰는 운영(예: 수업엔 2안, 공모전엔 3안)도 가능하다.
