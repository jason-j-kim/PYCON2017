# KWCI L3 토픽·키워드 사전 — 인수인계

**잠정판 1,523행 · 6개 도메인 · 18개국 · 11개 언어 · 2026-08**

이 문서 하나만 읽고 이어서 작업할 수 있게 썼습니다. 설계 근거가 필요하면
`01`(관광) · `02`(푸드) · `03`(소비재 통합)을 보시면 됩니다.

## 0. 가장 먼저 알아야 할 것

**이 사전을 그대로 분석에 쓰면 안 됩니다.**

```
실증 통과    450행  (30%)   ← 기존 486행 사전에서 승계 (KPOP · KVIDEO)
실증 대기  1,073행  (70%)   ← 신규. Trends 실측을 한 번도 거치지 않음
```

1,073행은 **신호가 있는지조차 확인되지 않았습니다.** 그 나라에서 실제로
쓰는 표기인지, 검색량이 0은 아닌지, TOPIC 후보에 MID가 붙는지 전부
미확인입니다. 모든 행이 `final_review_status = PENDING_EMPIRICAL_VALIDATION`
으로 표시돼 있습니다.

**인수받는 분의 1순위 작업이 이 실측입니다.** 그 전까지 이 사전은 후보
목록이지 계열이 아닙니다.

## 3. 행의 상태를 읽는 법

40열 스키마는 기존 사전 그대로입니다. 검증 수준은 다음 열로 읽습니다.

| 열 | 값 | 뜻 |
|---|---|---|
| `empirical_validation_status` | `EMPIRICALLY_VALIDATED` | Trends 실측 통과 |
| | `NOT_YET_TESTED` | **미실측** |
| `technical_status` | `PENDING_TOPIC_EXTRACTION` | MID 추출 대상 (373행) |
| | `PENDING_DOM_EXTRACTION` | 신호 유무만 확인하면 됨 |
| `selection_basis` | `EXPORT_REFERENCED` | 수출 품목이 범주를 지정 |
| | `MODE_GRAMMAR` · `RULE_GRAMMAR` | 소비양식/의도어 문법 (설계 재량 있음) |
| `extraction_method` | `COMPOSED` | 원산지×명사 조합 생성 |
| | `ATOMIC_LEXEME` | 외래어 개별 표기 |
| `ambiguity_flag` | `JP_DOMESTIC_COUNTERPART` | 일본 자국 대응물 오염 (§8) |
| `remaining_risk` | 자유 서술 | **그 개념이 못 잡는 것을 미리 적어 둔 것** |
| `source_url` | Trends explore URL | 그대로 열면 해당 질의 화면 |

`remaining_risk`는 특히 봐 주십시오. 실측에서 탈락할 것으로 **예상되는**
개념을 미리 적어 뒀습니다(예: `KFOOD_E09` 어묵은 직역어라 탈락 예상).
예상을 앞에 적어 두면 사후 합리화와 구분됩니다.

## 4. 다음 단계 — 순서대로

### 3-1. Trends 취득 경로 결정 ← **여기가 막혀 있습니다**

1,073행이라 수동 내려받기는 불가능합니다.

| 방법 | 문제 |
|---|---|
| pytrends | 비공식. 차단이 잦아 대규모 수집에 부적합 |
| 공식 Trends API | 승인 필요. 신청 후 대기 |
| 수동 CSV | 재현 불가 + 1,073회 |

**이 결정이 나기 전에는 그 뒤 단계를 설계할 수 없습니다.**

### 3-2. 기준어(anchor) 결정 — 같이 정해야 합니다

Trends는 **요청당 최대 5개를 0~100으로 상대 정규화**합니다. 1,073개를
215배치로 나눠 받으면 **배치마다 척도가 달라 이어붙일 수 없습니다.**

모든 배치에 **공통 기준어를 1개 넣어 재척도화**해야 합니다. 기준어 조건:

- 시간에 따라 안정적일 것 (계절성·이벤트가 없을 것)
- 전 국가에서 검색량이 충분할 것
- 도메인과 무관할 것 (한류 신호와 상관되면 안 됨)

이것을 안 정하고 수집하면 **전부 다시 받아야 합니다.** 데이터가 아니라
설계의 문제입니다.

### 3-3. 실측 — 신호 유무 + MID 추출

- 전 1,073행: 신호가 있는가 (검색량 0 / 데이터 부족 여부)
- TOPIC 후보 373행: DOM에서 MID가 잡히는가 → 잡히면 `topic`으로 승격

**무신호 탈락은 동결 위반이 아닙니다.** 회귀 결과를 보고 고치는 것이 아니라
기술적 사유이기 때문입니다. 다만 반드시 `technical_status`에 기록해서
사후 선택과 구분되게 해 주십시오.

### 3-4. 국가 × 월 시계열 수집

기간은 `2018-01-01`부터입니다. L1 패널의 기준연도와 맞춰 뒀으므로 같은
기준연도로 지수화됩니다.

### 3-5. L1 결합 → S3 회귀 + 위약검정

`kwci/trade/data/processed/panel.csv`가 종속변수입니다 (75품목 × 15개국 ×
2018~2024 = 7,875칸). 이 단계가 프로젝트에서 **아직 아무도 답하지 않은
질문**에 처음 닿습니다 — *"한국이 무엇을 얼마나 파는가"가 아니라 "그것이
한류 때문인가"*.

## 5. 위약 — 이 사전의 핵심 장치

수집할 때 **위약 계열을 빼지 마십시오.** 분석의 전제입니다.

| 도메인 | 위약 |
|---|---|
| KFOOD | 일식 · 중식 · 태국음식 |
| KBEAUTY | 일본 화장품 · **프랑스 화장품** |
| KFASHION | 일본 패션 · **이탈리아 패션** |
| KTOURISM | 일본 여행 · 태국 여행 |

"한국 화장품 검색이 늘었다"는 스킨케어 붐일 수도, 화장품 소비 증가 일반일
수도 있습니다. **위약에서도 계수가 유의하면 통제가 불충분한 것이므로 결과를
채택하지 않습니다.**

프랑스·이탈리아를 넣은 이유가 있습니다. 일본만 쓰면 **아시아 대 비아시아**
축이 통제되지 않습니다. 화장품·패션의 전통 강자를 상대로도 유의해야 "한류
때문"이라는 주장이 섭니다.

**주의.** 한식과 일식은 대체재이자 보완재라 위약 계수의 부호가 양쪽 다 나올
수 있습니다. 유의성만 보면 오독합니다 — **부호까지 함께 보십시오.**

### 위약이 성립하는 이유 — 조합 생성

질의를 손으로 쓰지 않고 조합했습니다.

```
질의 = 원산지 형용사(6종) × 범주 명사(33종) × 언어별 어순·성 일치
```

```
en   Korean food        | Japanese food      | Chinese food
ja   韓国料理            | 日本料理            | 中国料理
fr   cuisine coréenne   | cuisine japonaise  | cuisine chinoise
de   koreanisches Essen | japanisches Essen  | chinesisches Essen
```

**원산지만 다릅니다.** 손으로 쓰면 `한국 화장품`과 `프랑스 화장품`의 어휘
난이도가 달라져, 신호 차이가 관심의 차이인지 표현의 차이인지 구분되지
않습니다. 조합이 그 문제를 구조적으로 제거합니다.

`lexicon.py`의 `selftest()`가 33명사 × 11언어를 전수 검사합니다. **실패하면
사전이 생성되지 않습니다.** 명사를 추가하실 때 성(gender) 태그를 빠뜨리면
바로 걸립니다.

## 6. 이미 내린 결정들 — 되돌리려면 근거가 필요합니다

### 관광 36행을 178행으로 교체

기존 사전의 KTOURISM 36행 중 **33행이 영어 질의**였습니다
(`JP → "South Korea tourism"`). 각국의 영어 검색 가능 소수층을 재고 있고 그
비율은 국가마다 크게 다르므로 횡단 비교가 성립하지 않습니다.

**다만 기존 36행은 실증을 통과한 자료이고 신규 178행은 아닙니다.**
provenance상 후퇴입니다. 되돌리려면:

```
python build_master_dict.py --base ... --keep-old-tourism
python tourism/build_tourism_dict.py --conflicts    # 36건 대조
```

### 품목 1:1 번역 방식 폐기

`food/kfood_dict.csv`(358행)는 동결 품목 30개를 1:1로 옮긴 것입니다. 선정
재량이 0이라는 장점이 있지만 **아무도 `Korean instant rice`를 검색하지
않습니다.** 재량을 없애려다 측정 대상을 잃었습니다.

파일은 지우지 않았습니다. "품목 대응 계열"과 "일반 토픽 계열"을 대조하고
싶을 때 쓸 수 있습니다. **기본 계열은 `kconsumer_dict.csv`입니다.**

### 수출 품목은 앵커가 아니라 참고

품목 구성이 알려주는 것은 **어떤 범주가 크고 중요한가**입니다.

- K-Beauty: `330499` 기초화장품 **77.8억$ = 도메인의 78%** → 사실상 스킨케어.
  그래서 세럼·시트마스크·선크림·클렌징으로 갈라짐
- K-Fashion: 주얼리 · 티셔츠 · 가방 · 선글라스 · 스니커즈 순
- K-Food: 라면 13.6억$ · 김 4.8억$ · 과자 4.0억$ · 소스 3.7억$

수출에 대응 품목이 **없는데도** 넣은 것이 있습니다 — 떡볶이 · 한국치킨 ·
먹방 · 아이돌패션 · 스트릿웨어. HS로는 안 잡히지만 실제 관심의 큰
부분이고, **L1이 못 보는 것을 L3가 보는 자리**입니다. 이 괴리 자체가 분석
대상이 됩니다.

`selection_basis`로 `EXPORT_REFERENCED`와 `MODE_GRAMMAR`를 행 단위로
갈라 뒀습니다.

## 7. 중국 — 측정 사각지대

**전 도메인에서 제외돼 있습니다.** Google Trends가 차단된 시장이라 신호가
구조적으로 결측입니다. 기존 486행 사전에도 없었습니다.

이것은 편의가 아니라 **기록해야 할 한계입니다.** L1에서 중국은 K-Beauty·

대체 소스(Weibo·Baidu 지수)를 뚫든 결측으로 두든, **조용히 빼면 표본이
편향됩니다.** 논문·보고서에 반드시 명시해 주십시오.

## 8. 일본 — 오염 위험이 가장 큰 시장

일본은 거의 모든 한국 소비재 범주에 **자국 대응물**을 갖고 있습니다.

| 개념 | 순진한 질의 | 실제로 재는 것 | 사전이 쓴 질의 |
|---|---|---|---|
| 라면 | `ラーメン` | **일본 라멘** | `韓国ラーメン` |
| 소주 | `焼酎` | **일본 쇼추** | `韓国焼酎` |
| 김 | `のり` | **일본산 김** | `韓国のり` |
| 김치 | `キムチ` | 일본 국내 생산분 포함 | `韓国キムチ` |

수식어를 붙였지만 그만큼 검색량이 줄어 **과소측정 위험**이 남습니다. 완전한
해결책은 없습니다. 해당 4행에 `ambiguity_flag`를 달아 뒀으니 회귀에서 따로
보십시오.

**반대 방향의 위험도 있습니다.** 쿠션 파운데이션은 한국이 만든 제형이라
원산지 수식 없이도 한국 신호일 수 있습니다. `韓国クッションファンデ`로
한정하면 오히려 과소측정됩니다 (`KBEAUTY_E04`).

## 9. MID를 지어내지 마십시오

신규 1,073행에 `topic_mid`가 하나도 없습니다. 승계할 검증값이 없었기
때문입니다(관광 2개는 예외 — 기존 사전에서 IN·SA·AR로 실증된 값).

**그럴듯한 MID를 채워 넣으면 전혀 다른 개념을 재면서도 검증란이 차 있어
아무도 의심하지 않습니다.** 이 사전에서 가장 위험한 종류의 오류입니다.
MID는 반드시 Trends DOM에서 실측한 것만 넣어 주십시오.

## 10. 방법론적 지위 — 숨기지 않은 부분

L1 품목 사전은 BEC·공식분류·RCA·사전등록으로 **재량이 0**이었습니다.
이 사전은 그렇지 않습니다.

| 층 | 재량 | 근거 |
|---|---|---|
| 범주 개념 | 낮음 | 수출 상위 품목이 범주를 지정 |
| **소비양식·의도어 문법** | **있음** | 일반·요리법·외식·브랜드·미디어는 설계자 판단 |
| 질의 문자열 | 없음 | 조합기가 기계 생성 |
| 위약 | 없음 | 원산지만 교체 |

**문법을 고른 것은 재량입니다.** 다만 그 문법이 세 도메인과 위약에
**동일하게** 적용되므로 도메인 간·계열 간 비교에서는 상쇄됩니다. **절대
수준을 인용할 때만** 주의하시면 됩니다.

동결(`--freeze`)은 아직 하지 않았습니다. 검토 후 확정하실 때 도메인별
스크립트에서 실행하시면 sha256이 기록됩니다. 동결의 뜻은 **"검정 결과를
보고 질의를 고치지 않는다"** 이며, 무신호 탈락은 예외입니다.
