# KWCI L1(경제) — K-Food · K-Beauty · K-Fashion 수출 데이터 수집 계획

> 대상: KWCI(K-Wave Composite Index) 3레이어 중 **L1 경제(가중 0.5)**
> 범위: K-푸드 · K-뷰티 · K-패션 3개 도메인의 국가별 수출 실측
> 소스: 관세청 수출입무역통계 API · UN Comtrade API
> 작성 기준: KWCI 핵심 브리핑 v2 (산출 2026-06-28 / 심화 2026-07-04)

---

## 0. 이 작업의 위치 — 왜 지금 이것인가

브리핑 15쪽(통찰 ②, 사각 1)이 이 작업의 좌표를 정확히 지정한다.

> 콘텐츠 4분야(K팝·영상·게임·웹툰)의 수출은 전국 단위 통계라 국가별 비교에는 못 들어간다.
> **국가 비교에 실측 연결된 경제 데이터는 푸드·패션·뷰티(관세청)와 관광(관광공사)뿐이다.**

즉 L1은 가중 0.5로 지수의 절반을 차지하지만, 국가 비교(횡단 DSI)에서 실제로 작동하는 L1은 이 3개 도메인 + 관광이 전부다. **이 3개 도메인의 L1 품질이 KWCI 횡단 지수 전체의 신뢰도를 결정한다.**

부수 효과 하나가 중요하다. 무역통계는 플랫폼 신호와 달리 **중국이 정상적으로 포착된다.** 브리핑 15쪽의 "사각 2 — 플랫폼 차단"(중국 YouTube 조회수 0)이 L1에서는 발생하지 않는다. 따라서 이 작업은 통찰 ②의 측정 사각지대를 **부분적으로 메우는 역할**을 겸한다. 중국·러시아처럼 L3가 붕괴한 국가에서 L1은 유일하게 살아있는 신호다.

## 1. 핵심 질문 — "한류에 의해 영향받는 품목"을 어떻게 객관적으로 고르는가

### 1.1 순환논법의 위험

가장 흔한 실패는 이것이다.

> "라면·김치·화장품은 한류 품목이다. 왜냐하면 한류 덕분에 팔리니까."

이건 결론을 전제로 쓴 것이다. 브리핑 11~13쪽이 가중치에 대해 세운 원칙 — **"고정 사전은 출발점이고 최종 목적은 내생적 결정"** — 을 품목 선정에도 그대로 적용해야 한다. 사람이 "라면은 한류다"라고 선언하는 대신, 데이터가 **"라면 수출은 한류 신호에 반응한다"**를 말하게 한다.

### 1.2 객관적 기준이 갖춰야 할 4조건

| 조건 | 뜻 | 이 계획에서의 구현 |
|---|---|---|
| **사전명시성** | 검정 전에 후보와 기준을 고정 | Phase 1에서 후보 리스트를 동결하고 해시 기록 (사후 체리피킹 차단) |
| **재현가능성** | 제3자가 같은 데이터로 같은 결과 | 전 단계 코드·원시데이터·난수시드 저장 |
| **반증가능성** | 틀릴 수 있는 형태 | 위약검정(placebo) 필수 — 무관 품목은 탈락해야 함 |
| **외부앵커** | 자의성을 외부 권위로 대체 | UN BEC, 관세청·aT·KOTRA 공식 분류 채택 |

### 1.3 5단계 깔때기

```
S0  최종소비재 필터 (UN BEC)          HS6  5,611개  →  1,481개   [실측]
     ↓
S1  도메인 매핑 (공식 분류 채택)         1,481개  →    926개   [실측]
       K-Food 647 · K-Fashion 257 · K-Beauty 22
     ↓
S2  한국 특화도 (RCA ≥ 1)                926개  →      ?
     ↓
S3  한류 반응성 패널회귀 + 위약검정          ?    →      ?      ★ 핵심
     ↓
S4  문화 프리미엄 (초과점유율·단가)          ?    →  Tier 판정
```

S0·S1은 실측값이다(2026-07 산출). S2 이후는 Comtrade·관세청 수집 후 확정한다.

**S1 결과에 대한 두 가지 관찰**

- K-Beauty가 22개로 작은 것은 정상이다. HS 33류는 6단위 소호 자체가 적다. 품목 수가 아니라 수출액 규모로 판단할 문제다.
- K-Fashion 257개는 K-Food 647개보다 작아, 우려했던 "의류 세분류로 후보가 부풀어 오르는" 현상은 없었다. 다만 §4.2의 역직구 문제는 그대로 남는다 — 후보 수가 아니라 **실측 수출액이 비어 있을** 위험이다.

### S0의 한계와 예외 처리

첫 산출에서 **마른김(1212.21)과 인삼(1211.20)이 탈락했다.** BEC가 둘 다 중간재로 분류하기 때문이다.

이것은 BEC의 오류가 아니다. BEC의 end-use는 **경제적 기능**(투입재냐 최종재냐)을 재고, 1차 농수산물 원물은 추가 가공의 투입재가 될 수 있으므로 중간재로 잡는 것이 그 기준에서는 타당하다. 조미김이 HS 2106(기타 조제식료품)으로 분류되어 통과한 것과 대비된다.

문제는 **김이 한국 농수산식품 수출 최상위 품목**이라는 사실이다. 이대로 두면 K-Food 지수가 근본적으로 틀린다.

그래서 예외를 인정하되 세 조건을 건다. 자의적 끼워넣기와 구분되는 지점이다.

| 조건 | 내용 |
|---|---|
| **외부 앵커** | aT `K-Food+` 공식 품목군에 포함된 것만 |
| **사전등록** | S3 검정 **전에** 확정하고 동결 |
| **표시** | `s0_override` 플래그로 남겨 민감도 분석 가능 |

그리고 결정적으로, **예외는 후보 자격일 뿐이다.** S3(한류 반응성 회귀)는 예외 품목에도 똑같이 적용되며, 반응이 없으면 예외로 넣었더라도 Tier 1에 오르지 못한다.

동시에 `--dropped`로 **S0가 버린 도메인 대역 품목 전체를 열람 가능**하게 했다. 대표 품목이 조용히 사라지는 것이 이 지수에서 가장 위험한 실패이므로, 무엇이 탈락했는지가 항상 보여야 한다.

### S0. 최종소비재 필터 — UN BEC

**기준:** UN BEC(Broad Economic Categories) rev.5 기준 **Consumption goods**만 후보로 인정. UNSD가 공식 HS↔BEC 대응표를 배포한다.

**근거:** 한류는 **최종소비자의 문화적 선호**를 경유해서만 작동한다. 중간재·자본재는 원천적으로 무관하다. 이 한 단계가 다음을 자동 분리한다.

- 화장품 **원료**(HS 3823 지방산 등, 중간재) ↔ 화장품 **완제품**(HS 3304, 소비재)
- **원단**(HS 52~60, 중간재) ↔ **의류 완제품**(HS 61~62, 소비재)
- 식품 **첨가물**(중간재) ↔ **가공식품**(소비재)

이 구분을 사람이 손으로 하면 자의적이지만, BEC 대응표를 쓰면 외부 권위에 앵커된다.

### S1. 도메인 매핑 — 공식 분류 채택

우리가 만들지 않고 **채택**한다. 복수 분류를 교차해 합집합을 후보로, 교집합을 우선순위로 둔다.

| 도메인 | 앵커 분류 | HS 대역 (초안, S0 통과분에 한함) |
|---|---|---|
| **K-Food** | aT `K-Food+` 품목군, 농식품부 수출 통계 분류 | HS 02~04, 07~09, 11~12, 15~22 |
| **K-Beauty** | 대한화장품협회 수출 분류, MTI 소비재 | HS 3303~3307, 3401.30, 9616 |
| **K-Fashion** | KOTRA·산업부 소비재 수출 분류, MTI 의류·잡화 | HS 61, 62, 64, 65, 4202, 7113, 7117, 9003~9004 |

**중요:** 이 표는 *대역*이지 *확정 품목*이 아니다. 확정은 S2~S4의 산출이다.

### S2. 한국 특화도 — RCA (현시비교우위)

**지표:**

```
RCA_j = (한국의 j 수출 / 한국 총수출) ÷ (세계의 j 수출 / 세계 총수출)
```

**기준:** `RCA_j ≥ 1.0` (세계 평균 이상으로 한국이 특화한 품목)

**성격:** Balassa(1965) 이래 국제 표준 지표. Comtrade만으로 완전 재현 가능. 자의적 판단 0.

**예상되는 진단적 가치:** 라면·김·김치·조미김은 RCA가 10을 크게 넘을 것으로 예상되고, 반대로 **일반 의류는 RCA가 1 미만일 가능성이 높다.** 후자가 중요하다 — 이건 기준의 실패가 아니라 **K-Fashion의 실체를 드러내는 성공**이다(§4.2 참조).

### S3. 한류 반응성 검정 — 이 계획의 핵심

품목이 한류 신호에 **실제로 반응하는지**를 통계적으로 검정한다.

**모형 (패널 이원 고정효과):**

```
ln(V_ijt) = β · ln(KWave_{i,t-k}) + γ′X_{it} + μ_ij + λ_t + ε_ijt
```

| 기호 | 내용 |
|---|---|
| `V_ijt` | 국가 i · 품목 j · 분기 t 의 한국 수출액 (관세청) |
| `KWave_{i,t-k}` | 국가 i의 한류 신호, 시차 k분기 — KWCI의 **L3(수용자)** 또는 K영상·K팝 DSI |
| `X_it` | 통제변수: 파트너 GDP, 실질환율(KRW/현지통화), **해당 품목의 파트너 총수입액**, FTA·관세 더미 |
| `μ_ij` | 국가×품목 고정효과 (시불변 요인 흡수: 거리·문화권·식습관) |
| `λ_t` | 시간 고정효과 (글로벌 충격 흡수: 코로나·유가·물류대란) |

**표준오차:** 국가 수준 클러스터. 패널 상관 고려.

**채택 기준:**
1. `β̂ > 0`
2. `p < 0.05`
3. 시차 `k ∈ {0,1,2,3}` 중 **선행 관계가 성립하는 최적 시차가 존재** (한류 신호가 수출에 선행)

**위약검정 (필수):**

동일 모형을 **문화적으로 무관한 품목**에 적용한다.

- HS 8542 반도체
- HS 2710 석유제품
- HS 8901 선박
- HS 8703 승용차 (경계 사례 — 흥미로운 대조군)

이들에서 `β`가 유의하게 양(+)으로 나오면, **모형이 GDP·환율·경기를 제대로 걸러내지 못한 것**이다. 그 경우 통제변수를 재설계하고 다시 돌린다. 이 검정을 통과하지 못한 결과는 채택하지 않는다.

**왜 이 단계가 핵심인가:** 브리핑 12쪽이 Entropy 가중에 대해 남긴 문장 — *"신호가 좋아지면 가중이 스스로 반응한다는 증거"* — 의 품목 선정판이다. 그리고 브리핑 21쪽의 자기교정(동호회 규모 → 실측 차트)과 같은 성격의 장치다. **품목 목록이 틀렸을 때 그것을 드러내는 기제**를 미리 심어 둔다.

**인과 단정 금지:** 브리핑 28쪽 구축 3원칙 중 *"인과 단정 금지 — 상관·시차·인과 가능성을 구분해 검증"*. 이 회귀는 **조건부 상관과 선행성**을 보이는 것이지 인과를 확정하지 않는다. 산출 문서에 그대로 표기한다.

### S4. 문화 프리미엄 검정 — 미러 데이터

S3을 통과해도 "그냥 소득이 늘어서 더 샀다"와 "한국 것이라서 샀다"는 구분되지 않는다. 두 지표로 나눈다.

**(a) 초과점유율 (Excess Share)**

```
XS_ij = (파트너 i의 j 수입 중 한국산 비중) − (세계의 j 수입 중 한국산 비중)
```

한류 강국에서 한국산 점유율이 세계 평균보다 유의하게 높으면, 그 초과분이 문화 프리미엄의 후보다.

**(b) 단가 프리미엄 (Unit Value Premium)**

```
UP_ij = (파트너 i가 수입하는 한국산 j의 단가) ÷ (파트너 i가 수입하는 j 전체의 평균 단가)
```

**같은 라면 1kg을 더 비싸게 사준다** — 이것이 문화 프리미엄의 가장 순수한 형태다.

**판정:** KWCI 상위 5개국에서의 `XS`·`UP`이 하위 5개국 대비 유의하게 높은가.

두 지표 모두 **파트너 신고 수입 데이터(mirror)**가 있어야 계산된다. 관세청 단독으로는 불가능하고 Comtrade가 필수인 이유다(§3.1).

### 1.4 Tier 판정 및 재판정

| Tier | 조건 | 지수 반영 |
|---|---|---|
| **Tier 1 — 핵심 대표품목** | S2 ∧ S3 ∧ S4 | L1 core basket, 정상 가중 |
| **Tier 2 — 연관품목** | S2 ∧ S3 | L1 산입, 감쇄 가중 |
| **Tier 3 — 관찰품목** | S0∧S1 통과, S3 미달/미검정 | 지수 미산입, 모니터링만 |

**목표 규모:** 도메인당 Tier 1 **5~8개 품목**. 이것이 브리핑이 요구한 "대표 품목"이다.

**품목 내 가중:** Tier 1 내부 가중은 브리핑 12쪽의 **Entropy 가중**을 그대로 적용한다 — 국가 간 구분력(`d_j = 1 − E_j`)이 높은 품목에 큰 가중. 단순 수출액 비중 가중과 병렬 산출해 비교한다.

**재판정 주기:** 연 1회. **품목 구성 자체가 시변한다**는 점이 중요하다. 2018년의 한류 품목과 2025년의 한류 품목은 다르다. 이는 브리핑 13쪽 IPCA의 *"국면이 바뀌면 가중이 스스로 바뀐다"*는 철학과 정합한다.

## 2. 무엇을 측정하는가 — 총액 · 총량 · 단가

요청하신 "총량, 총액수"에 **단가**를 반드시 추가해야 한다.

| # | 지표 | 단위 | 소스 | 의미 |
|---|---|---|---|---|
| 1 | **총액** | USD (천불) | 관세청 `expDlr` | 규모 |
| 2 | **총량** | kg | 관세청 `expWgt` | 실물 침투 |
| 3 | **단가** | USD/kg = ①÷② | 파생 | **문화 프리미엄의 자리** |

### 2.1 왜 단가가 결정적인가

브리핑 4쪽이 지적한 기존 논의의 "한계 2 — 볼륨 편중"에 대한 직접적인 답이 단가다.

| 총액 | 총량 | 단가 | 진단 |
|---|---|---|---|
| ↑ | ↑ | ↑ | **한류형 성장** — 프리미엄을 동반한 확대 ★ |
| ↑ | ↑ | ↓ | 가격경쟁형 확대 — 물량 밀어내기, 한류 효과 아님 |
| ↑ | ↓ | ↑↑ | 고급화·니치 전환 |
| ↓ | ↓ | ↑ | 시장 축소 중 고급 잔존 |

**같은 "수출 증가"라도 이 4분면 중 어디냐에 따라 정책 처방이 정반대다.** 총액만 보면 1행과 2행을 구분할 수 없고, 그러면 "볼륨 편중"의 함정에 그대로 빠진다.

### 2.2 보너스 — 품목·시장 다변화

브리핑 16쪽(통찰 ③, 계란 바구니)의 ENM·HHI를 **관광에서 수출로 확장**한다.

- **시장 다변화**: 품목 j의 수출이 몇 개국에 분산되어 있는가 (`ENM = 1/HHI`)
- **품목 다변화**: 도메인 d의 수출이 몇 개 품목에 분산되어 있는가

방한 관광이 중국 재집중으로 다변화 93.8(2018년 이하)로 후퇴한 것과 같은 구조적 취약성이 K-Food·K-Beauty 수출에도 존재하는지 확인한다. 특히 **K-Beauty의 중국 의존도**는 사전 가설로 둘 만하다.

## 3. 데이터 소스 — 두 API의 역할 분리

### 3.1 핵심 프레이밍: 대체재가 아니라 분자와 분모

두 소스를 "둘 다 수출 데이터니까 골라 쓴다"고 보면 설계가 무너진다. **정확한 관계는 이것이다.**

| | 관세청 | UN Comtrade |
|---|---|---|
| **역할** | **분자** — 한국의 수출 실적 | **분모** — 세계·파트너의 총수입 |
| 신고 주체 | 한국 (수출 신고) | 각국 (수입 신고, 미러) |
| 가격 기준 | FOB | CIF (수입 기준) |
| HS 정밀도 | 최대 10단위 (HSK) | 6단위 |
| 주기 | 월 (속보성 높음) | 연·월 (지연 있음) |
| 시의성 | 익월 초 | 6~18개월 지연 |
| **담당 지표** | 총액 · 총량 · 단가 · 시계열 | **RCA · 초과점유율 · 단가프리미엄** |

**RCA·초과점유율·단가프리미엄은 전부 분모가 필요하다.** 한국이 얼마를 팔았는지(관세청)만으로는 "세계 평균 대비"를 계산할 수 없다. 그래서 Comtrade가 선택이 아니라 필수다.

이는 브리핑 14쪽의 *"실물 통계가 닻, 플랫폼 신호가 돛"*과 같은 구조다. **관세청이 닻(정본·시계열), Comtrade가 좌표계(국제 비교 기준선).**

### 3.2 관세청 수출입무역통계 API

- **경로:** 공공데이터포털(data.go.kr) — 관세청 무역통계 API군
- **주 활용:** 품목별·국가별 수출입실적 (HS 부호 + 국가코드 + 기간)
- **응답 필드(예상):** `expDlr`(수출금액, 천USD), `expWgt`(수출중량, kg), `impDlr`, `impWgt`
- **인증:** data.go.kr `serviceKey`
- **⚠ Phase 0에서 실검증할 것:** 정확한 오퍼레이션명·파라미터명·HS 자릿수 제약·기간 제약·일일 호출 한도는 **실호출로 확인 후 확정**한다. 문서상 스펙과 실제 동작이 어긋나는 사례가 흔하다.

**별도 수집 필요:** 관세청 **전자상거래 물품 수출입실적** 통계 (§4.2 참조).

### 3.3 UN Comtrade API

- **경로:** `comtradeapi.un.org/data/v1/get/C/{A|M}/HS`
- **인증:** `Ocp-Apim-Subscription-Key` 헤더. 무료 구독 티어 존재(일일 호출·레코드 상한 있음). 키 없이 쓰는 preview 엔드포인트는 행 수 제한이 커서 본 수집에는 부적합.
- **주요 파라미터:** `reporterCode`(한국 = 410), `partnerCode`, `period`, `cmdCode`, `flowCode`(X=수출, M=수입)
- **미러 수집:** `reporterCode=파트너국, partnerCode=410, flowCode=M` — 파트너가 신고한 對한국 수입
- **⚠ 무료 티어 쿼터가 병목이다.** 15개국 × ~250개 후보 HS × 8년이면 호출이 급증한다. **증분 적재 + 로컬 캐시 + 요청 배치화가 설계 전제**여야 한다.

## 4. 알려진 함정 — 지금 결정해야 할 것들

### 4.1 HS 코드 개정 (2018~2025는 두 개의 판이 걸쳐 있다)

수집 구간이 **HS2017**과 **HS2022** 두 판에 걸친다. 2022년 개정에서 식품·화장품 일부 코드가 이동·분할·통합됐다.

**대응하지 않으면 2022년에 가짜 점프 또는 가짜 붕괴가 생긴다.** 브리핑이 기준연도 2018=100을 쓰는 이상, 이건 지수 전체를 오염시키는 문제다.

**처리:** WCO/UNSD **correlation table**로 전 구간을 **HS2022 기준으로 통일**한다. 1:N·N:1 매핑은 안분 규칙을 명시하고 로그로 남긴다.

### 4.2 ★ K-Fashion 구조적 함정 — 이 계획 최대의 리스크

한국의 의류 수출 통계는 **한류 효과를 거의 잡지 못할 가능성이 높다.** 이유는 셋이다.

1. **일반 무역통계의 의류 수출 상당분이 OEM·원부자재**다. 브랜드 완제품이 아니다.
2. **한국은 의류 순수입국**이다. RCA가 1을 밑돌 공산이 크다(S2에서 대량 탈락).
3. **결정적 — K-Fashion의 실제 수출 경로는 역직구(전자상거래)다.** 무신사·에이블리·지그재그 등을 통한 D2C 판매는 소액 **목록통관**으로 나가며, 일반 무역통계에서는 과소계상되거나 품목 식별이 불가능하다.

**결론:** 일반 무역통계만으로 K-Fashion L1을 만들면 **거의 무의미한 숫자**가 된다. 브리핑 6쪽에서 K패션 DSI가 26.63으로 8개 도메인 중 최하위인 것이, 실제 약세인지 **측정 실패**인지 현재로선 구분되지 않는다.

**대응:** 관세청 **전자상거래 수출입 통계를 별도 계열로 병행 수집**한다. 이것 없이는 K-Fashion 결과에 브리핑 15쪽 "측정 사각지대"와 동급의 경고를 달아야 한다.

이는 **지금 결정이 필요한 사안**이다(§6).

### 4.3 재수출·중계무역

홍콩·싱가포르·아랍에미리트향 수출은 **최종 소비국이 아닐 수 있다.** 한국→홍콩 화장품 수출의 상당분이 중국 재수출이라는 것은 업계 상식이다.

**처리:** 파트너 미러 데이터로 교차 확인하고, 중계 허브 국가는 별도 플래그. 15개국 패널에서 이들이 상위에 오면 **해석 시 반드시 병기**한다.

### 4.4 FOB / CIF 격차

관세청 수출(FOB)과 파트너 수입(CIF)은 운임·보험만큼 체계적으로 다르다(통상 5~15%).

**원칙:** 두 소스의 **절대치를 한 문장에서 혼용 금지.** 비율·순위·추세만 교차 사용한다. — 브리핑 22쪽 "함정 3: 절대치를 단독 인용한다"와 동일한 규율이다.

### 4.5 소액·결측 처리

국가×품목 셀 상당수가 0 또는 결측이다. `ln(0)` 문제, 소액 셀의 단가 폭주(분모가 작아 USD/kg이 튀는 현상)를 처리해야 한다.

**처리:** PPML(Poisson Pseudo-Maximum Likelihood) 추정 병행, 단가는 winsorize, 최소 거래액 임계 설정.

### 5.0.2 수집 과정에서 확인된 API 제약

계획서 §3.2에서 "실호출로 확인 후 확정"이라 유보했던 사항의 실측 결과다.

**관세청** (`apis.data.go.kr/1220000/nitemtrade/getNitemtradeList`)

- 응답은 **XML**. `type=json` 파라미터는 무시된다
- 성공 판정은 `resultCode=00`. 오류도 HTTP 200으로 오고, `resultMsg` 는
  "정상서비스."(한글)와 "NORMAL SERVICE."(영문)가 섞여 나오므로 문자열로
  가리면 성공을 오류로 읽는다
- **1회 조회기간은 1년 이내** (`resultCode=99`). 연도별로 나눠 호출해야 한다
- 응답에 `총계` 행이 포함된다. 연간 실적은 이 행을 쓴다
- 금액 `expDlr` 는 **달러**(천달러 아님), 중량 `expWgt` 는 kg
- 호출당 약 4초로 느리다. 순차로는 928건에 65분이라 병렬(동시 8)이 필요하다

**UN Comtrade** (`comtradeapi.un.org/data/v1/get/C/A/HS`)

- `reporterCode=0`(세계 집계)은 **빈 응답**. reporterCode 를 생략하면 전
  신고국이 오므로 이를 합산해 세계 총계를 만든다
- `cmdCode`·`period` 는 콤마로 묶을 수 있다
- **`motCode`·`customsCode`·`partner2Code` 를 지정하지 않으면 분해 차원을
  모두 돌려주어 한 신고국이 여러 행으로 중복된다.** 첫 산출에서 세계 총수출이
  55조$(공표 24조$의 2.3배)로 나온 원인. `motCode=0, customsCode=C00,
  partner2Code=0` 을 명시하면 해소된다
- 무료 티어는 **429(Rate limit)** 를 낸다. 동시 호출 없이 간격 2초 + 백오프
- `cmdCode=TOTAL` 은 응답이 수 MB라 타임아웃을 300초로 잡아야 한다
- 한도 헤더를 주지 않아 잔여 쿼터를 알 수 없다
- **2024년 신고국이 138개로 2023년 165개보다 적다.** 세계 합계가 과소집계되어
  2024 RCA가 부풀 수 있으므로, 절대 기준(RCA≥1) 판정은 2023을 주 기준으로 삼는다

**P1의 "동결 + 해시"가 방법론적으로 중요하다.** 검정 결과를 보고 후보를 손보면 S3 전체가 무의미해진다. 사전등록(pre-registration)의 최소 형태다.

### 5.0 실행 환경 — 로컬 필수 (원격 불가)

원격 클라우드 세션에서 확인한 사실:

```
unstats.un.org:443     CONNECT 403  (조직 egress 정책 차단)
comtradeapi.un.org:443 CONNECT 403  (동일)
```

**Comtrade 수집은 원격 환경에서 원천적으로 불가능하다.** §3.1에서 정리했듯 Comtrade는 RCA·초과점유율·단가프리미엄의 **분모**를 담당하므로, 이게 막히면 S2·S4가 통째로 돌지 않는다. 여기에 더해:

- 관세청 API는 한국 서비스라 해외 IP에서 동작이 달라질 수 있고, 실패 시 **스펙 문제인지 네트워크 문제인지 구분되지 않는다** (Phase 0의 목적 자체가 무력화)
- 원격 컨테이너는 세션 종료 시 소멸 → 수집 데이터가 날아가고 Comtrade 일일 쿼터를 재소모
- API 키를 원격에 옮기지 않는 편이 낫다

**결론: Phase 0~4 전부 로컬에서 수행한다.** 원격은 키·네트워크가 불필요한 작업(방법론 문서, 리팩터링, 코드 리뷰)만 담당한다. 같은 브랜치를 공유하므로 왕복에 마찰은 없다.

## 6. 지금 결정이 필요한 사항

| # | 쟁점 | 선택지 | 권고 |
|---|---|---|---|
| 1 | **전자상거래(역직구) 통계 포함** | 포함 / 제외 | **포함, 단 별도 계열로 분리 표기.** K-Fashion 성패를 좌우 (§4.2) |

| 6 | 한류 신호 대리변수 | L3 종합 / K팝·K영상 DSI / Trends 단독 | **주: L3 종합, 부: K영상 DSI** — 강건성으로 병렬 검정 |

## 7. 이 설계가 브리핑과 이어지는 지점

| 브리핑 | 이 계획에서의 구현 |
|---|---|
| 통찰 ① 두 개의 자 (10쪽) | 총액·총량은 시계열(2018=100), RCA·XS는 횡단(0~100). 산출 스키마에서 분리 |
| 통찰 ② 측정 사각지대 (15쪽) | **L1은 중국이 포착된다** — L3 붕괴 국가의 유일한 살아있는 신호. 단 K-Fashion은 새로운 사각지대(§4.2) |
| 통찰 ③ 계란 바구니 (16쪽) | ENM·HHI를 관광에서 수출로 확장. K-Beauty 중국 의존도가 사전 가설 |
| 통찰 ④ 위상 vs 행동 (20쪽) | 총량(행동·물량) vs 단가(위상·프리미엄)의 분리. §2.1의 4분면 |
| 외생 → 내생 (11~13쪽) | 품목 선정 자체를 회귀로 내생화(S3), 품목 내 가중을 Entropy로(§1.4) |
| 자기교정 (21쪽) | 위약검정을 상시 장치로 내장 — 품목 목록이 틀렸을 때 드러나게 함 |
| 인과 단정 금지 (28쪽) | S3은 조건부 상관·선행성만 주장. 산출 문서에 명기 |
