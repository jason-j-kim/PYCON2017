# data/fiscal.json — 세출예산 로컬 검색 데이터

선례 조사 축(축 B)의 **재정(집행) 소스**다. API가 아니라 정적 파일이며, 예산 데이터가
연 1회 갱신되므로 실시간 조회가 필요 없다. 이 파일이 없으면 재정 소스는 건너뛰고
나머지 두 소스(PRISM·의안)로만 진행한다(미조회는 미발견으로 처리하지 않는다).

## 만드는 법 (연 1회)

1. 공공데이터포털에서 CSV를 내려받는다 (인증키 불필요):
   `재정경제부_세목 예산편성현황(총지출)` — https://www.data.go.kr/data/15083329/fileData.do
   최근 5개 연도(예: 2022~2026)면 종료 판정에 충분하다.
2. 전처리:
   ```
   node scripts/build_fiscal.mjs 2022.csv 2023.csv 2024.csv 2025.csv 2026.csv
   ```
   → `data/fiscal.json` 생성 (세목 행을 세부사업명+연도로 집계).
3. 실제 CSV 헤더에 맞게 `scripts/build_fiscal.mjs` 상단의 컬럼 후보와 **금액 단위**를
   확인·조정한다.

## 형식

```json
{"unit": "원",
 "items": [
   {"name": "청년월세 한시 특별지원", "ministry": "국토교통부",
    "series": [{"year": 2022, "amount": 102000000000},
               {"year": 2024, "amount": 0}]}
 ]}
```

최근 연도 예산이 0이거나 그 연도 레코드가 없으면 종료된 사업으로 판정된다.
바로 배열(`[{...}]`)로 두어도 읽힌다.
