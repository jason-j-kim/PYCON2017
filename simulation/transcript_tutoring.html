세션 A — 대화 전문

제안된 아이디어
온라인으로 학생과 과외 선생님을 연결해주는 앱을 만들면 어떨까요. 시간과 장소 상관없이 원하는 과목 선생님을 찾을 수 있어서 많은 학생들이 편하게 이용할 것 같습니다.
[턴 1] 제안자온라인으로 학생과 과외 선생님을 연결해주는 앱을 만들면 어떨까요. 시간과 장소 상관없이 원하는 과목 선생님을 찾을 수 있어서 많은 학생들이 편하게 이용할 것 같습니다.
[턴 2] 질문자(명료화)시간과 장소의 제약을 없앤다는 방향은 알겠는데, "많은 학생"이 구체적으로 어떤 대상인가요? 예를 들어 초중고생인지, 특정 과목 수요가 있는 학생인지, 그리고 이 앱이 없으면 그들이 지금 겪는 가장 큰 불편은 무엇인가요?
[턴 3] 제안자그냥 초중고생 전체를 생각했어요. 다들 과외 선생님 구하기 힘들어하니까 이 앱으로 편하게 찾을 수 있을 것 같습니다. 지금은 학원이나 지인 소개로 찾아야 해서 불편한 걸로 알고 있어요.
[턴 4] 질문자(명료화)초중고생 전체와 지인 소개로 찾는 불편함을 짚어주셨네요. 그렇다면 이 아이디어를 "누구를 위해, 어떤 문제를, 어떻게 해결한다"는 한 문장으로 정리하면 어떻게 말씀하시겠어요?
[턴 5] 제안자과외 선생님을 구하기 힘든 초중고생을 위해, 지인 소개나 학원에 의존해야 하는 불편함을 앱으로 원하는 선생님을 쉽게 찾을 수 있게 해서 해결한다, 이렇게 정리할 수 있을 것 같아요.
[턴 6] 질문자(독창성)한 문장으로 명확하게 정리해주셨네요. 그런데 이미 숨고, 크몽, 과외의신 같은 앱들이 비슷하게 학생과 과외 선생님을 연결해주고 있는데, 이 아이디어가 그것들과 구체적으로 무엇이 다른가요?
[턴 7] 제안자그런 앱들이 있다는 건 알고 있는데, 저희 앱은 좀 더 사용하기 편하고 학생 입장에서 더 직관적으로 만들려고 합니다. 기존 앱들보다 화면 구성이나 검색 과정을 간편하게 해서 더 편리하게 이용할 수 있을 것 같아요.
[턴 8] 질문자(독창성)"더 편리하게"라는 방향은 알겠는데, 화면 구성이나 검색 과정이 간편해서 좋다는 건 경쟁 앱들도 다음 업데이트에서 쉽게 따라 할 수 있는 부분 아닐까요? 그렇게 됐을 때도 사용자가 계속 당신의 앱을 선택할 이유가 남아있나요?
[턴 9] 제안자음... 그 부분은 확실히 약점인 것 같아요. 따라 하면 저희만의 이유가 크게 남지는 않을 것 같긴 한데, 그래도 먼저 편하게 만들어서 사용자들을 좀 더 모으면 괜찮지 않을까 싶습니다.
[턴 10] 질문자(독창성)약점을 솔직하게 인정하신 부분이 이후 논의에 도움이 될 것 같아요. 그런데 "먼저 편하게 만들어서 사용자를 모은다"는 전략은 결국 속도 싸움인데, 숨고나 크몽처럼 이미 사용자와 자본을 확보한 곳들과 속도로 경쟁했을 때 이길 근거는 무엇인가요?
[턴 11] 제안자그 부분은... 사실 이길 근거를 명확히 말씀드리기는 어려울 것 같아요. 아무래도 자본이나 사용자 규모에서 밀리는 건 사실이니까요. 그래도 처음에는 좁은 지역이나 특정 학년 대상으로 작게 시작해서 입소문을 내보면 어떻게든 되지 않을까 하는 생각입니다.
[턴 12] 질문자(실용성)좁은 지역이나 특정 학년으로 시작 범위를 좁히신 건 실행 가능성을 높이는 좋은 방향이네요. 그렇다면 그 좁힌 범위 안에서 가장 먼저 만들어야 할 최소 기능, 즉 이것 없이는 서비스가 성립하지 않는 핵심 기능은 무엇이라고 보시나요?
[턴 13] 제안자일단 학생이 원하는 과목이랑 지역을 입력하면 선생님 목록이 뜨고, 프로필 보고 연락할 수 있는 기능이 제일 기본이라고 생각해요. 검색하고 매칭해주는 기능만 있어도 일단 서비스는 돌아갈 것 같습니다.
[턴 14] 질문자(실용성)검색과 매칭이라는 핵심 기능을 명확히 짚으셨네요. 그런데 그 목록에 뜰 "선생님"은 처음에 어떻게 확보하실 건가요? 학생이 검색했을 때 프로필이 텅 비어 있다면 서비스가 성립할 수 있을까요?
[턴 15] 제안자그 부분은 아직 구체적으로 생각은 못했는데, 처음에는 대학생 과외 선생님들한테 홍보를 해서 직접 등록해달라고 부탁드리면 될 것 같아요. 주변에 과외하시는 분들도 있고 커뮤니티 같은 데 올리면 몇 분은 등록해주시지 않을까 싶습니다.
[턴 16] 질문자(실용성)초기 선생님 확보 방법을 구체적으로 생각해주셨네요. 그런데 "몇 분"이 등록해준다고 했을 때, 특정 지역·학년으로 좁혔다면 학생이 검색했을 때 원하는 과목의 선생님이 실제로 나타날 확률은 얼마나 될까요? 예를 들어 처음 목표로 하는 지역에서 몇 명 정도의 선생님을 확보해야 서비스가 "성립한다"고 보시나요?
[턴 17] 제안자정확한 숫자를 딱 정해두지는 않았는데, 그래도 한 지역에 못해도 몇십 명 정도는 있어야 학생들이 검색했을 때 뭔가 뜨긴 뜨지 않을까 싶어요. 정확히 몇 명이 있어야 확률이 얼마나 되는지는 계산해보지 않아서 지금 말씀드리기는 어려울 것 같습니다.
[턴 18] 질문자(수용태도)정확한 숫자는 아직이지만 최소한의 규모 감각은 짚으셨네요. 그런데 지금 지인 소개나 학원으로 잘 구해지고 있는 학생·학부모라면, 검증되지 않은 신생 앱에 아이를 맡길 선생님을 굳이 찾아 나설 이유가 있을까요? 반대로 지금 방식에 불만이 큰 사람은 구체적으로 누구인가요?
[턴 19] 제안자그 말씀도 맞는 것 같아요. 지금 방식에 만족하는 분들은 굳이 옮길 이유가 없을 것 같고, 아마 지인 소개나 학원 근처에 없어서 선생님 찾기 어려운 분들이 더 필요로 하지 않을까 싶습니다. 그런데 그게 정확히 어떤 사람들인지는 조사해보지 않아서 구체적으로 말씀드리기는 어려울 것 같아요.
[턴 20] 질문자(수용태도)조사가 안 됐다는 걸 인정하신 점은 다음 단계로 넘어가는 데 중요한 지점이네요. 그런데 이 서비스가 자리 잡으면, 지금 학원이나 개인 소개로 학생을 안정적으로 받고 있는 과외 선생님들 입장에서는 굳이 수수료를 떼는 플랫폼에 등록할 이유가 있을까요?
[턴 21] 제안자그 부분도 사실 약점인 것 같아요. 이미 안정적으로 학생 받고 계신 선생님들은 굳이 수수료 떼면서까지 등록할 이유는 없을 것 같고, 아마 이제 막 시작하거나 학생이 부족한 선생님들 위주로 등록하시지 않을까 싶은데, 그래도 충분할지는 잘 모르겠습니다.
[턴 22] 질문자(수용태도)이제 막 시작하거나 학생이 부족한 선생님 위주로 모인다는 점을 짚으셨는데, 그렇다면 학생 입장에서도 검증된 베테랑 선생님보다는 경력이 적은 선생님들 위주로 만나게 될 가능성이 높다는 뜻이 되나요? 그렇다면 애초에 "원하는 선생님을 쉽게 찾는다"던 처음의 가치 제안과는 어떻게 이어질까요?
[턴 23] 제안자그렇게 보면 좀 모순되는 것 같긴 하네요. 처음엔 원하는 선생님을 쉽게 찾는다고 했는데, 실제로는 경력 적은 선생님들 위주로 모일 가능성이 크니까 학생들이 기대하는 것과는 다를 수 있을 것 같아요. 이 부분은 저도 지금 딱히 좋은 해결책이 떠오르지는 않습니다.
[턴 24] 질문자(자기 평가)처음의 가치 제안과 실제로 모일 선생님 풀 사이의 모순까지 스스로 짚어내셨네요. 지금까지 나온 이야기들을 돌아봤을 때, 이 아이디어가 살아남으려면 가장 먼저 풀어야 할 단 하나의 약점은 무엇이라고 보시고, 그걸 어떻게 보완하시겠어요?
[턴 25] 제안자가장 먼저 풀어야 할 건 역시 좋은 선생님을 충분히 확보하는 부분인 것 같아요. 그게 안 되면 다른 건 다 의미가 없으니까요. 근데 구체적으로 어떻게 해결할지는 저도 좋은 방법이 딱히 떠오르지는 않고, 일단 홍보를 더 열심히 하는 수밖에 없지 않을까 싶습니다.
